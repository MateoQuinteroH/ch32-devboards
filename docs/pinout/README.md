# Diagramas de pinout

Guarda aquí, para cada placa:

- `x035-pinout.svg` / `l103-pinout.svg`: diagrama para publicar.
- El archivo fuente editable (por ejemplo Inkscape `.svg` o `.drawio`), para que otros puedan actualizarlo.

Consejo: mantén el orden y los nombres de los pines idénticos a la serigrafía de la placa.
