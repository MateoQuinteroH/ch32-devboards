# Código de conducta

Este proyecto adopta el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

En resumen: trata a todas las personas con respeto, acepta las críticas constructivas y enfócate en lo que es mejor para la comunidad. No se toleran el acoso ni los ataques personales.
